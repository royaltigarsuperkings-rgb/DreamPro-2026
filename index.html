🔢 Number Limit (auto close)
Highest total count allowed on ONE number (all users together), for each draw. First type the limits and the special numbers, then press Turn ON. While it is OFF nothing is limited. 0 = no limit for that type. The ALL box is used for every type whose own box is 0. Change the values any time. You can also Close / Open any number by hand below. The limit is checked by the Firebase server on every save, so it works even when the Main Admin app is closed. A user whose count is more than what is left gets only the remaining count; a full number is refused.
⭐ Special numbers (limit / close)
Choose the type, type ONE or MANY numbers (separated by space, comma or new line), then either give them their own limit or close them. Choose one shift or all shifts. It works every day and is checked by the Firebase server. A number has ONE special setting; saving it again replaces the old one. Limit empty or 0 = NO limit for these numbers. Remove a number from the list below to go back to the normal limit.

Add New User
Passwords: minimum 6 characters. Sub Admin: can log in with ANY name, only the password is checked (each Sub Admin needs a different password). Main Sub Admin: must use this exact username.
Team Update (one time)
Adds the team name list to every user and every old entry, so a Main Sub Admin can read only his own team. Do this once, when the new app is installed. It is safe to tap again.
Change My Password (Main Admin)
Type your current password, then the new one twice. The new password works from the next login. The old one stops working.
Force Reset Password
Use this when a user forgets the password: you set a new one directly, without needing the old one (minimum 6 characters). Old users marked ⚠ must be activated here once: set a password for them.
Block / Unblock User
A blocked user cannot type numbers or save entries (the app logs him out at once). Old entries, results and settlement stay. Tap again to Unblock.
